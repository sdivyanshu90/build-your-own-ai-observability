Next steps
----------

1. Create the first organization, project and API key:

     kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "aiobs.fullname" . }}-api -- \
       aiobs-admin bootstrap --email you@example.com

   The API key is printed once and stored only as a keyed hash. Copy it now.

2. Confirm the platform can reach everything it needs:

     kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "aiobs.fullname" . }}-api -- \
       aiobs-admin check-dependencies

3. Point an SDK at it:

     export AIOBS_ENDPOINT={{ .Values.config.publicUrl }}
     export AIOBS_API_KEY=<the key from step 1>

SQLite analytics driver, a filesystem object store, anonymous ingest, a
